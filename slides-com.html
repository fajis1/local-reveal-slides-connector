Slides.com handoff

This project stays local and credential-free. Open the presentation with the Reveal viewer, then use Slides.com’s Reveal.js import workflow to make an editable copy in your own account.

Open the Slides.com Reveal.js import guide

A direct automated publish is deliberately not configured here: it requires a private Slides.com credential. Keep that credential in a local, ignored slides-com.config.json file or an authenticated local bridge—never in GitHub.
